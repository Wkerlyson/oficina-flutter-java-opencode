# Do App à API: Flutter, Java e IA generativa com OpenCode
 
Repositório de apoio da oficina prática de desenvolvimento para estudantes de Sistemas de Informação. Em cerca de 2 horas, criamos um app Flutter e uma API Java (Spring Boot) e usamos o OpenCode para gerar parte do código a partir de prompts.

## Tecnologias
 
- **Flutter** (Dart) para o app mobile, com o Android Studio
- **Java 17 e Spring Boot** para a API, com o IntelliJ IDEA
- **OpenCode** como agente de programação no terminal, para gerar código a partir dos prompts
- **Git** e **GitHub** para versionamento
## Estrutura do repositório
 
```
.
├── instalacao-ferramentas/   Guia de instalação e checklist de verificação
└── oficina/                  Prompts da oficina e materiais de apoio
```
 
### `instalacao-ferramentas/`
 
Guia passo a passo para preparar o computador antes da oficina, no Windows:
 
- Git e Node.js
- JDK 17 e configuração do `JAVA_HOME`
- Android Studio, Flutter SDK e `flutter doctor`
- IntelliJ IDEA
- OpenCode
- Problemas comuns e checklist final
Leia esta pasta primeiro e marque o checklist antes de ir para a oficina.
 
### `oficina/`
 
Prompts prontos, separados por etapa, para criar as funcionalidades do app Flutter e da API passo a passo com o OpenCode. Também contém o plano B: app Flutter e API já prontos, para acompanhar caso algum passo não funcione no tempo da oficina.
 
## Como usar
 
1. Instale as ferramentas seguindo o guia em `instalacao-ferramentas/`.
2. Confirme o checklist final.
3. Clone este repositório:
```bash
git clone LINK_DO_REPOSITORIO
cd do-app-a-api
```
 
4. Abra a pasta `oficina/` e siga os prompts na ordem indicada.
## Pré-requisitos
 
- Windows 10 ou 11 (64 bits)
- 16 GB de RAM recomendados e 25 GB livres em disco
- Virtualização habilitada na BIOS (necessária para o emulador Android)
- Conta no GitHub
- Acesso ao provedor de IA que será informado pelo instrutor
## Contexto
 
Material preparado para a Semana de Atualização, cujo tema geral é Games. O objetivo é mostrar que as tecnologias existem, como elas se integram e como ferramentas de IA podem acelerar o desenvolvimento, sem substituir o entendimento do código.
